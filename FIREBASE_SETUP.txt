STEGO SOCIETY POS — FIREBASE SETUP

Firebase project:
stego-society

1. Authentication
   - Enable Email/Password.
   - Create Owner and Staff accounts.

2. Firestore users collection
   Document ID = Firebase Authentication UID.

   Owner example:
   name  (string) = Azeel
   role  (string) = owner
   email (string) = owner email

   Staff example:
   name  (string) = Staff Name
   role  (string) = staff
   email (string) = staff email

3. Firestore Rules
   - Open Firestore Database > Rules.
   - Replace current rules with the content of firestore-rules.txt.
   - Publish.

4. GitHub Pages
   - Upload ALL files from this folder to the repository root.
   - index.html is the main entry file.

This build uses ONLY Firebase project: stego-society
It does not use Meney Firebase.
